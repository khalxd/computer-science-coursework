# Web Development Projects

## Overview

This folder contains introductory web development projects completed during my computer science coursework.

The projects focus on building responsive web pages using HTML and CSS while recreating common search engine interfaces and layouts.

## Projects

### Google Search
A homepage that replicates the Google Search interface.

### Google Images
A Google Images search page with a similar layout and styling.

### Google Advanced Search
A recreation of Google's Advanced Search page using HTML forms and CSS.

## Skills Demonstrated

- HTML5
- CSS3
- Form creation
- Responsive page layout
- UI design
- Basic web development principles

## Technologies

- HTML5
- CSS3

## Learning Outcome

These projects helped develop a strong understanding of front-end web development fundamentals, including page structure, styling, forms, and recreating real-world user interfaces.
